# SkillSpring — React learning and skill tracker

## Run in VS Code
1. Install Node.js 18+ from https://nodejs.org/
2. Extract this ZIP and open the `SkillSpring` folder in VS Code.
3. Choose Terminal → New Terminal.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local URL Vite prints (usually http://localhost:5173).

## Features
- Responsive learning dashboard
- Course progress cards
- Skill goal tracking
- Add your own learning goals
- Mark tasks complete
- Search courses
- Saves goals and tasks in your browser with localStorage

This is a frontend demo using sample data. It has no backend, authentication server, or cloud database.
